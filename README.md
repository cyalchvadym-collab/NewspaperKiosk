# ЛР5 — Кіоск газет та журналів (Console, .NET 8)

Тема: **Кіоск газет та журналів**.

У цій лабораторній реалізовано:
- ролі: Адміністратор / Покупець / Продавець;
- робота зі списками (додавання, видалення, пошук, сортування, статистика);
- **ЛР5: збереження та завантаження даних з файлів** (JSON) через `FileDataHandler`.

## Як запустити (JetBrains Rider)
1. Відкрити папку `ConsoleApp1`
2. Запустити `Program.cs`

Дані зберігаються в `ConsoleApp1/bin/.../data/*.json` (поруч із exe).
